## 🏥 Healthcare & Medical (10 datasets)

### 1. MIMIC-III Critical Care Database
- **Description**: De-identified health data from 40,000+ ICU patients
- **Size**: 47,000+ patients, 58,000+ admissions
- **Access**: [PhysioNet](https://physionet.org/content/mimiciii/) (requires credentialing)
- **Use Cases**: Mortality prediction, length of stay, treatment optimization
- **Format**: CSV, PostgreSQL

### 2. NIH Chest X-ray Dataset
- **Description**: 112,120 frontal-view chest X-rays from 30,805 patients
- **Size**: ~45GB
- **Access**: [NIH Clinical Center](https://www.nih.gov/news-events/news-releases/nih-clinical-center-provides-one-largest-publicly-available-chest-x-ray-datasets-scientific-community)
- **Use Cases**: Disease classification, image segmentation
- **Format**: PNG images + CSV labels

### 3. COVID-19 Open Research Dataset (CORD-19)
- **Description**: 1M+ scholarly articles about COVID-19 and related coronaviruses
- **Access**: [Semantic Scholar](https://www.semanticscholar.org/cord19)
- **Use Cases**: Literature review, NLP, knowledge graphs
- **Format**: JSON

### 4. Cancer Genome Atlas (TCGA)
- **Description**: Multi-dimensional cancer genomics data
- **Access**: [TCGA](https://www.cancer.gov/tcga)
- **Use Cases**: Genomic analysis, survival prediction
- **Format**: Various (BAM, VCF, TSV)

### 5. NHANES (National Health and Nutrition Examination Survey)
- **Description**: US population health and nutrition data
- **Access**: [CDC NHANES](https://www.cdc.gov/nchs/nhanes/)
- **Use Cases**: Epidemiology, public health research
- **Format**: SAS, CSV

### 6. UK Biobank (Limited Access)
- **Description**: 500,000+ participants' health records
- **Access**: [UK Biobank](https://www.ukbiobank.ac.uk/)
- **Use Cases**: Disease genetics, lifestyle analysis
- **Format**: CSV, specialized formats

### 7. PhysioNet Databases
- **Description**: Multiple physiological signal databases
- **Access**: [PhysioNet](https://physionet.org/about/database/)
- **Use Cases**: ECG analysis, sleep studies, vital signs
- **Format**: WFDB, CSV

### 8. ADNI (Alzheimer's Disease Neuroimaging Initiative)
- **Description**: Brain imaging and biomarker data
- **Access**: [ADNI](http://adni.loni.usc.edu/)
- **Use Cases**: Alzheimer's research, brain imaging
- **Format**: NIfTI, CSV

### 9. OpenNeuro
- **Description**: Free and open platform for neuroimaging data
- **Access**: [OpenNeuro](https://openneuro.org/)
- **Use Cases**: fMRI analysis, brain research
- **Format**: NIfTI, BIDS

### 10. Medical Segmentation Decathlon
- **Description**: 10 medical image segmentation tasks
- **Access**: [Medical Segmentation Decathlon](http://medicaldecathlon.com/)
- **Use Cases**: Image segmentation, deep learning
- **Format**: NIfTI

## 📥 How to Use These Datasets

### In Course Labs
Each module includes labs using relevant datasets from this catalog. Example:
```python
# Load dataset using Hugging Face
from datasets import load_dataset
dataset = load_dataset("imdb")

# Load from UCI
import pandas as pd
url = "https://archive.ics.uci.edu/ml/machine-learning-databases/iris/iris.data"
df = pd.read_csv(url, header=None)

# Use OLLAMA to explore
import requests
response = requests.post("http://localhost:11434/api/generate", json={
    "model": "llama3",
    "prompt": f"Analyze this dataset structure: {df.head()}"
})
```

### Dataset Selection Guide
- **Beginners**: MNIST, Iris, Titanic (Kaggle)
- **Intermediate**: CIFAR-10, IMDB, Yahoo Finance
- **Advanced**: ImageNet, Common Crawl, MIMIC-III

### Ethical Considerations
- Always check dataset license
- Respect privacy and anonymization
- Cite dataset sources properly
- Be aware of biases in data
