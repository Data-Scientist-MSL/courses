# MVP Learning Path

## Overview

This document defines the **Minimum Viable Product (MVP)** learning path - the core curriculum a learner must complete to achieve foundational competency in modern data science and AI/ML.

**Time Commitment**: 3-4 months (15-20 hours/week)  
**Outcome**: Job-ready data scientist with practical ML/AI skills

---

## 🎯 MVP Path Overview

### Core vs. Optional Content

| Track | Core Modules (MVP) | Optional/Advanced |
|-------|-------------------|-------------------|
| **Track 0** | Module 01: Scientific Tooling | Modules 00, 02 |
| **Track 1** | Modules 01, 02, 03 | Module 04 |
| **Track 2** | Module 05: MLOps | Module 06 |

**Total MVP Modules**: 5 core modules  
**Total Optional Modules**: 4 enhancement modules

## 💡 Tips for MVP Success

### 1. Time Management
- **Dedicate consistent time**: 15-20 hrs/week is better than sporadic bursts
- **Use OLLAMA AI tutor**: Don't get stuck for hours - ask AI for help
- **Time-box labs**: Spend max 2-3 hours per lab, move on if stuck

### 2. Learning Efficiency
- **Code along**: Don't just read - run every code example
- **Modify examples**: Change parameters, try different datasets
- **Build while learning**: Apply concepts to personal projects immediately

### 3. Staying Motivated
- **Track progress**: Use the checklist above
- **Join community**: GitHub Discussions, Discord, Reddit
- **Share work**: Tweet progress, blog about learnings
- **Celebrate wins**: Completed lab? Deployed model? Celebrate!

### 4. Getting Unstuck
- **Use AI tutor first**: Ask OLLAMA before searching online
- **Read error messages**: 80% of issues are in the error message
- **Check documentation**: Official docs > random tutorials
- **Ask for help**: GitHub Discussions after 30 min stuck
