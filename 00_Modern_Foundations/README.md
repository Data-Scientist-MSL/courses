# 🌟 Track 0: Modern Foundations

This track establishes the foundational knowledge and tools for modern data science practice in 2026.

## 📚 Modules

### Module 00: Philosophy of AI-Human Augmentation
**Duration**: 1 week  
**Objective**: Understand AI as cognitive extension, not replacement

**Topics**:
- The Augmented Human Framework
- Scientific Tooling for Daily Life
- Ethics of Human-AI Collaboration
- Privacy and Data Sovereignty

**Practical Applications**:
- Personal knowledge assistant with RAG
- Quantified self dashboard
- Productivity analyzer

**Resources**:
- See: [`docs/AUGMENTED_HUMAN_PHILOSOPHY.md`](../../docs/AUGMENTED_HUMAN_PHILOSOPHY.md)

---

### Module 01: Scientific Tooling Ecosystem
**Duration**: 1 week  
**Objective**: Master modern development environment

**Topics**:
- Python ecosystem (conda, pip, venv)
- Jupyter Lab and notebooks
- VS Code + extensions
- Git and GitHub workflows
- Docker fundamentals

**Tools**:
- Python 3.11+
- Jupyter Lab
- VS Code with Python extension
- Git/GitHub
- Docker Desktop

**Labs** (Coming Soon):
- Lab 1: Setting up reproducible Python environment
- Lab 2: Jupyter best practices
- Lab 3: Git workflows for data science
- Lab 4: Docker basics

---

### Module 02: Modern Data Engineering
**Duration**: 1 week  
**Objective**: Work with modern data pipelines and formats

**Topics**:
- Data formats (Parquet, Arrow, JSON, CSV)
- REST APIs and GraphQL
- SQL and NoSQL databases
- Data validation and quality
- Vector databases (Chroma, Pinecone)

**Practical Projects**:
- Build API data pipeline
- Create data validation system
- Set up vector database for RAG

**Datasets**:
- Public APIs (weather, finance, news)
- Open datasets (Kaggle, UCI)

---

## 🎯 Learning Path

1. Start with **Module 00** to understand the philosophy
2. Set up your environment with **Module 01**
3. Learn data engineering basics in **Module 02**
4. Move to Track 1: Core AI/ML

## 📊 Prerequisites

- Basic programming knowledge (any language)
- High school mathematics
- Curiosity about data and AI

## ⏱️ Time Commitment

- **Total**: 3 weeks
- **Hours per week**: 10-15 hours
- **Self-paced**: Complete at your own speed
